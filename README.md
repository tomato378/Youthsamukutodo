# YouthSamuku — イベント準備タスク管理ツール

オフライン国際交流イベントの準備タスクを可視化・共有するWebアプリです。  
イベントを登録すると、開催日から逆算した準備タスクを自動生成し、3人の運営メンバーで進捗を共有できます。

## 主な機能

- **イベント作成** — 開催日・時間・会場・運営メンバー3人を登録
- **タスク自動生成** — 開催日から逆算して22個の準備タスクを自動生成、担当者も自動割り当て
- **3つのビュー** — 一覧表 / カンバン / 危険タスク を切り替えて確認
- **全体ダッシュボード** — 全イベント横断で「期限切れ」「今日まで」「3日以内」「未担当」「確認待ち」を一括確認
- **タスク編集** — 担当者・期限・進捗・メモを各タスクで変更可能
- **進捗4段階** — 未着手 / 進行中 / 確認待ち / 完了
- **レスポンシブ対応** — PC・スマホ両対応

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` をブラウザで開いてください。

データは**ブラウザのlocalStorage**に保存されます（サーバー不要、すぐに動作確認できます）。

## Supabaseへの移行（本番運用）

3人で共有URLを使う場合は、Supabaseをバックエンドとして使用します。

1. [Supabase](https://supabase.com) でプロジェクトを作成
2. `supabase/schema.sql` をSQL Editorで実行
3. `.env.local.example` をコピーして `.env.local` を作成し、URLとAnon Keyを設定
4. `lib/storage.ts` をSupabaseクライアント実装に差し替え（関数シグネチャは同一）

## 担当者の自動割り当てルール

| メンバー | 担当タスクカテゴリ |
|---------|-----------------|
| メンバー1 | イベント企画・コンテンツ・台本 |
| メンバー2 | 告知・SNS・フォーム・連絡 |
| メンバー3 | 会場・備品・当日運営 |
| 未担当 | クロスファンクションな意思決定・最終確認 |

担当者は登録後に手動で変更できます。
